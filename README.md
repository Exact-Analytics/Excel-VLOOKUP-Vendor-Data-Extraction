# 📊 Excel VLOOKUP Automation: Vendor Data Extraction

An automated Microsoft Excel solution designed to populate a list of fruit transactions that have empty vendor and purchase month details.

## 💼 Project Overview
The objective of this project was to automatically pull missing transactional information from a separate vendor data table to complete the primary dataset.

## 🛠️ Technical Implementation
*   **Data Retrieval:** Utilized `VLOOKUP` to match fruit names and extract the correct Vendor and Purchase Month.
*   **Formula Architecture:** Applied absolute cell references to lock the reference table, allowing the formula to be seamlessly flash-filled down the column.
*   **Exact Match Logic:** Configured the lookup range to `FALSE` to guarantee exact string matching.
*   **Data Auditing:** Maintained visibility of `#N/A` results to identify which specific fruits were missing from the master vendor list.
